5. A/B 解读（任务诚实报告铁律）
-----------------------------------------------------------
[原假设] Context-IR prompt 工艺 → 制作完成度 显著上升、综合分 上探

[结果]
  - 制作完成度：Δ = 0 （control 50 vs experiment 50，**完全没动**）
  - 综合加权  ：Δ = +2.5 (63.6 → 66.1)，**落在 σ 噪声内**
                (control σ=5.59, experiment σ=4.16，Δ < 1σ)
  - 角色一致性：Δ = +3 (刚好踩在 Δ<3 阈值的边界，且 control σ=8.57，
                Δ < 1σ，不显著)

→ 结论 1：**线 0 假设未验证** ——
  任务硬指标「制作完成度 显著上升 + 综合分 上探」**未达成**。
  Δ=0 / Δ=+2.5 都在 σ 噪声内，按 §6 诚实报告铁律必须如实写明。

[附带观察 — 非假设目标维度]
  Context-IR 工艺确实在以下维度产生了**较大正向偏移**（虽然同样落在 σ 内）：
  - 镜头语言 +8 (63 → 71)：Context-IR 的 [Shot N] 段内多镜头结构
    （"At 00:04.500, the camera cuts to ..."）让模型生成了更清晰的景别切换
  - 风格与氛围 +10 (68 → 78)：integrated_multimodal_description 把 Mai Yoneyama
    + neon CMYK 风格块字面一致地钉在每段开头，模型对风格锚定的"重复强化"响应更明显
  - 档次定位 +7 (60 → 67)：上面两个维度提升的连带效应

  这三个维度都是**间接维度**（不是任务假设的直接目标）。
  假设的直接目标「制作完成度」完全没有变化（0 vs 0）。

[根因分析]
  任务假设的「Context-IR 提升制作完成度」隐含的前提是 prompt 内嵌的
  in-segment transition + 跨镜指代会反映成"剪辑完成度"评分提高。但 VLM 的
  「制作完成度」维度在原 v3.2 prompt 里**显式评分点**是"字幕、标题卡、
  片头/片尾、包装"——30s 验证版本来就没有 intro/outro 标题卡（任务
  §2 拍点对齐里说"按 30s 截取/调整"，v3.2 的 60s MV + 标题卡被有意
  省略了），所以无论 control 还是 experiment 都在「制作完成度」上拿 50 分
  —— 两者都没有"包装"可评，Δ 自然为 0。

  → 这是**任务设计层面的天花板**：30s 验证版没有"完成度"上限可挖。
     Context-IR 工艺的真正效果（连续性 / 段内多镜头 / 跨切音频连续）
     需要在 60s+ 全片 + 有 intro/outro 的版本里才能被「制作完成度」维度
     量化捕捉到。30s 验证版的制作完成度天然就是 50 左右。

[综合 σ 解读]
  experiment σ=4.16 < control σ=5.59 —— Context-IR prompt 让模型生成
  的内容**更稳定一致**（variance 更小）。这是工艺升级的一个**附带收益**，
  但不影响"是否显著提升"这个二分判断。
