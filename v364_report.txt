### Step 3：拼接 → `scripts/compose_final_v364.py`

vs compose_final_v363.py 关键差异（任务书 §4.3）：

1. **输出改为 768x1344 竖屏**：`RES_W=768, RES_H=1344`
   → 所有 `scale=768:1344:flags=lanczos:force_original_aspect_ratio=decrease,
                pad=768:1344:(ow-iw)/2:(oh-ih)/2:black`
2. **pix_fmt 强制 yuv420p**：concat 和 xfade 命令都加 `-pix_fmt yuv420p`
3. **Step 0 trim 头部 0.5s**：每段 H3 输出 trim 前 0.5s（去白淡入）
4. 硬切段间 → concat demuxer（沿用 v363）
5. dissolve 段间 → xfade + 0.06s MARGIN（沿用 v363）

ffmpeg 命令链：

```bash
# Step 0: trim head 0.5s × 6 shots
ffmpeg -y -ss 0.5 -i clips_v364/shot01.mp4 -c:v libx264 -crf 18 -an \
       -vf "scale=768:1344:flags=lanczos:force_original_aspect_ratio=decrease,
            pad=768:1344:(ow-iw)/2:(oh-ih)/2:black,setsar=1:1,format=yuv420p" \
       -pix_fmt yuv420p -movflags +faststart clips_v364_trimmed/shot01.mp4
# (× 6 shots)

# Step 1: group concat (硬切组内 concat demuxer)
ffmpeg -y -f concat -safe 0 -i group_00.list.txt -c:v libx264 -crf 20 \
       -vf "scale=768:1344:...,format=yuv420p" -an -r 24 \
       -pix_fmt yuv420p -movflags +faststart -fflags +genpts \
       group_00.mp4
# group_00 = shot01+02+03+04 → 32.833s
# group_01 = shot05 → 6.083s
# group_02 = shot06 → 7.500s

# Step 2: dissolve xfade + MARGIN
ffmpeg -y -i group_00.mp4 -i group_01.mp4 \
       -filter_complex "[0:v]format=yuv420p,scale=768:1344:...,fps=24[lv];
                       [1:v]format=yuv420p,scale=768:1344:...,fps=24[rv];
                       [lv][rv]xfade=transition=dissolve:duration=0.300:offset=32.473[vout]" \
       -map [vout] -c:v libx264 -crf 20 -an -r 24 -pix_fmt yuv420p \
       -movflags +faststart -fflags +genpts chain_01.mp4
# offset = 32.833 - 0.300 - 0.060 = 32.473
# 安全断言: offset + xfade_d = 32.773 < current_dur - 0.05 = 32.783 ✓

# Step 3: BGM 铺底
ffmpeg -y -i chain_02.mp4 -stream_loop -1 -i bgm_v32.wav \
       -filter_complex "[1:a]atrim=0:45.583,asetpts=PTS-STARTPTS,
                        aformat=sample_rates=32000:channel_layouts=stereo,
                        volume=0.85[bgm];
                        [bgm]alimiter=limit=0.95,loudnorm=I=-16:TP=-1:LRA=11[aout]" \
       -map 0:v -map [aout] -c:v copy -c:a aac -b:a 192k -ar 32000 \
       -shortest -movflags +faststart final_v36_60s_v364.mp4
```
