## 1. 问题定位（来自任务书，根因已由 Hermes 确认）

v3.3 成片三个转场问题：
1. 转场时画面先变成「空白帧」再出现彩色爆炸特效 → 转场被 H3 当独立画面生成
2. 某一转场特效在一段视频里反复出现 → 转场词写死、模板轮用
3. 多个转场与场景内容无关、像硬切 → 转场是独立美术素材叠加，非语义衔接

根因：
- `scripts/storyboard_v32.py` 在每个 shot 的 `scene` 描述和 `timed_shot_list` 里**写死转场词**（color_explosion / ink_burst / fabric_wipe / diagonal_slash / comic_panel_split / whip_pan / halftone_flash，"COLOR EXPLOSION TRANSITION" 行）。
- `scripts/prompt_pack_v34.py` 的 `build_prompt` 把 `shot.scene` 写进 `[SCENE]`、把 `timed_shot_list` 经 `rewrite_shot_timeline_p2` 写进 `[SHOT_TIMELINE]` → 转场词进了 H3 生成 prompt。
- H3 不理解转场，把「COLOR EXPLOSION TRANSITION」当独立画面生成 → 空白帧+爆炸。
- v34 拼接层 `compose_final_v34.py` 用纯 concat demuxer 硬拼（无 xfade）。

## 3. Step 1：storyboard_v35.py（生成层去转场词）

复制 v32 SHOTS 结构（同一题材「选学姐还是学妹」双角色对比，6 段 × 10s = 60s），
但：
- **删除每个 shot 的 `transition_in` / `transition_out` 字段**（不再写死转场类型）
- **scene 描述重写**：只描述镜头内容、画面、构图、角色动作，**不含任何转场特效词**
  （explode / burst / wipe / slash / split / ink / radial sunburst 等）。保留
  「静态视觉内容」描述（halftone dot pattern、pop-art sticker、cel-shading 等
  风格锚定词不算转场词）。
- **timed_shot_list 删除所有 TRANSITION 行**，只保留镜头内容的时间线
- 保留 camera / include_senior / include_junior / ending_frame_cue 等所有
  非转场字段
- 输出：`output/pipeline_v35/sb/storyboard_v35.json`

**关键修改点**（与 v32 对比）：
| 字段 | v32 | v35 |
|------|-----|-----|
| `transition_in` / `transition_out` | 6 个 shot 都有写死 | 全部删除 |
| scene 含 "explode" / "burst" / "radial sunburst" | 是 | 否 |
| scene 含 "ink_burst" / "color explosion" | 是 | 否 |
| timed_shot_list 含 "[4s] COLOR EXPLOSION TRANSITION — ..." | 是 | 否 |
| `transition_governance` 元数据 | 无 | 有（policy + allowed_types + fancy_budget_max） |

## 4. Step 2：transition_planner_v35.py（语义匹配转场规划）

**输入**：storyboard_v35（shots 列表）
**输出**：`output/pipeline_v35/sb/transition_plan_v35.json`

**核心函数** `plan_transitions(shots) -> list[dict]`（纯 Python，无随机）：
1. `compute_shot_signals(shot)`：从每段抽 6 类语义信号
   - `char_focus` / `has_senior` / `has_junior`（结构化字段）
   - `objects`：场景/时间线文本里的物体 token（ring / petal / ribbon /
     cardigan / blazer / column / book / garden / cat / cherry tree 等）
   - `colors`：色板 token（magenta / cyan / lemon yellow / neon CMYK /
     cobalt / navy / cream / halftone / fluorescent green 等）
   - `locations`：场景 token（garden / column / cherry tree / frame 等）
   - `cam_type` / `walking`：相机类型与运动类型
   - `ending_cue`：终幅构图

2. `pair_score(a, b)`：相邻镜头对 (a, b) 打分
   - char_continuity：同角色焦点 +3，solo↔group +1，swap +0
   - object_continuity：|A∩B|（cap 3）
   - color_continuity：|A∩B|（cap 3）
   - location_continuity：|A∩B|（cap 3）
   - motion_bonus：双 walking +2，同 camera type +1
   - total = sum

3. `decide(score, detail, fancy_used)`：决策表
   - score ≥ 6 + 运动延续 → dissolve (0.4s, plain)
   - score ≥ 6（无运动）→ dissolve (0.3s, plain)
   - score 3..5 → 短 dissolve (0.3s, plain)
   - score < 3 + 强风格延续 → fade（fancy, budget）
   - score < 3 + 运动延续 + 风格统一 → fadeblack（fancy, budget）
   - score < 3 默认 → hard_cut (0.0s)
   - fancy (fadeblack + fade) 全局 ≤ 2

4. **确定性**：相同 SHOTS 跑 3 次结果完全一致（无 random 模块调用）

## 5. Step 3：compose_final_v35.py（ffmpeg 真实 xfade 拼接）

**复用 v34 音频混音范式**（`mix_unified_bgm` + loudnorm），但视频拼接用
**ffmpeg xfade filter**（不是纯 concat）。

**关键技术细节**：
- xfade 类型映射：v35 4 种 → ffmpeg xfade 名称
  - `hard_cut` → `fade` (duration=0.001 等效硬切)
  - `dissolve` → `dissolve`
  - `fadeblack` → `fadeblack`
  - `fade` → `fade`
- **累积式 offset**（per v31_concat.py 累积逻辑）：
  - `offset[i] = cursor + segment_durations[i] - xfade_d[i]`
  - `cursor += segment_durations[i] + segment_durations[i + 1] - xfade_d[i]`
- 音频：acrossfade `d=<dur>:c1=tri:c2=tri`，前置 `aresample=44000,aformat=stereo`
- 分辨率 1344x768 @ 24fps（与 v34 一致）
- `--dry-run`：只打印完整 ffmpeg 命令链不执行（用 placeholder shot 路径占位）
