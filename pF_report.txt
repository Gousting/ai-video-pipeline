3. scripts/vlm_config.py 设计
================================================================================

3.1 设计目标
  - 单文件、单 import，依赖仅 Python 标准库（os / sys / pathlib）
  - 三层兜底解析：进程环境变量 → .env 文件 → 默认值
  - 提供 self-test：`python scripts/vlm_config.py` 一行验证
  - API_KEY 输出脱敏（前 6 + 后 2，中间 *），避免日志意外泄漏
  - 兼容 layers（Phase F 兼容层 + Phase F2 双分组：本任务书要求 API_KEY/API_URL/MODEL）

3.2 路径解析
  - _SCRIPT_DIR = Path(__file__).resolve().parent
  - _REPO_ROOT  = _SCRIPT_DIR.parent          → D:\ai-video-pipeline
  - _ENV_PATH   = _REPO_ROOT / ".env"         → D:\ai-video-pipeline\.env

3.3 .env 解析（手写，stdlib-only）
  - 按行 splitlines()，strip 后 partition('=', 1)（避免 value 内的 '=' 被破坏）
  - 容忍成对 ' 或 " 包裹（_strip_quotes）
  - 忽略空行 / 行首 # / 整行 # 开头注释
  - KEY 重名后者覆盖前者（与 python-dotenv 行为一致）
  - 解析失败仅打印 WARN（一个格式瑕疵不拖垮脚本启动）
  - 文件不存在 → 返回空 dict，触发 env var → 默认值 兜底链

3.4 _resolve 优先级链
  def _resolve(name, default, file_values):
      val = os.environ.get(name)              # 1. 进程环境变量
      if val not in (None, ""): return val
      val = file_values.get(name)             # 2. .env
      if val not in (None, ""): return val
      return default                          # 3. 兜底默认

3.5 暴露常量
  VLM_API_KEY / VLM_API_URL / VLM_MODEL      ← Phase F2 显式前缀（视觉）
  CHAT_API_KEY / CHAT_API_URL / CHAT_MODEL    ← Phase F2 显式前缀（文本，预留）
  API_KEY / API_URL / MODEL                  ← Phase F 兼容别名（=VLM 组，等价指针）

3.6 _mask_key 脱敏
  - len <= 8 → "前2***后2"
  - len >  8 → "前6 + (len-8) 个 * + 后2"
  - 实际输出：sk-VxL + 59 个 * + Zr（len=67）
